# Turn-Based Battle Game

## Beschrijving
Dit is een turn-based battle game waarbij spelers strategisch tegen elkaar vechten met karakters die unieke stats hebben. Het project gebruikt C# voor de backend met een SQLite database, en React voor de frontend.
